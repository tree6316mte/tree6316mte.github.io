      Q 1780. 종이의 개수

      Q 1780. 종이의 개수

      문제 바로가기


      분류

      분할 정복


      문제 및 풀이

      ❔ 문제

      N×N크기의 행렬로 표현되는 종이가 있다. 종이의 각 칸에는 -1, 0, 1 중 하나가 저장되어 있다. 우리는 이 행렬을 다음과 같은 규칙에 따라 적절한 크기로 자르려고 한다.

      1. 만약 종이가 모두 같은 수로 되어 있다면 이 종이를 그대로 사용한다.
      2. (1)이 아닌 경우에는 종이를 같은 크기의 종이 9개로 자르고, 각각의 잘린 종이에 대해서 (1)의 과정을 반복한다.

      이와 같이 종이를 잘랐을 때, -1로만 채워진 종이의 개수, 0으로만 채워진 종이의 개수, 1로만 채워진 종이의 개수를 구해내는 프로그램을 작성하시오.

      ⌨️ 입력

      첫째 줄에 N(1 ≤ N ≤ $3^7$, N은 $3^k$ 꼴)이 주어진다. 다음 N개의 줄에는 N개의 정수로 행렬이 주어진다.

      🧾 출력

      첫째 줄에 -1로만 채워진 종이의 개수를, 둘째 줄에 0으로만 채워진 종이의 개수를, 셋째 줄에 1로만 채워진 종이의 개수를 출력한다.


      💡 풀이

      분할 정복 알고리즘을 이용해서 푸는 문제이며 다음과 같이 풀 수 있습니다.

      Q. 만약 9x9 문제가 주어졌을 경우

      1. 먼저 스택에 9x9 문제를 넣습니다.

      2. 스택에 있는 문제(9x9)에서 작은 문제(3x3)로 9분할 하기 전에 먼저, 문제의 정수가 모두 같은 지 확인합니다.

      3. 모든 정수가 같을 경우와 다를 경우로 나뉩니다.

      • 같다면 작은 문제로 분할 하지 않고, 해당 정수(-1,0,1)의 위치에 맞게 갯수를 +1 하면 됩니다.
      • 다르다면 작은 문제(3x3)로 9등분 하여 스택에 저장 후 다시 2번으로 돌아가 2번->3번을 반복 합니다.
      1. 스택에 남아있는 문제가 없다면 저장했던 정수(-1,0,1)들의 갯수를 출력합니다.

      📄 C# 코드

      main.cs
      using System;
using System.Collections.Generic;

internal class Program
{
  static bool isSame(int[,] arr, int x, int y, int size)
  {
      int whatNum = arr[x, y];
      for (int i = x; i < x + size; i++)
      {
          for (int j = y; j < y + size; j++)
          {
              if (arr[i, j] != whatNum)
                  return false;
          }
      }
      return true;
  }

  static int[] Solution(int[,] arr)
  {
      int[] answer = new int[3];
      Stack<(int, int, int)> stack = new Stack<(int, int, int)>();
      stack.Push((0, 0, arr.GetLength(0)));

      while (stack.Count > 0)
      {
          var (x, y, size) = stack.Pop();

          if (isSame(arr, x, y, size))
          {
              answer[arr[x, y] + 1]++;
          }
          else
          {
              size /= 3;
              stack.Push((x, y, size));
              stack.Push((x, y + size, size));
              stack.Push((x, y + size * 2, size));
              stack.Push((x + size, y, size));
              stack.Push((x + size, y + size, size));
              stack.Push((x + size, y + size * 2, size));
              stack.Push((x + size * 2, y, size));
              stack.Push((x + size * 2, y + size, size));
              stack.Push((x + size * 2, y + size * 2, size));
          }
      }

      return answer;
  }

  static void Main(string[] args)
  {
      if (int.TryParse(Console.ReadLine(), out int iT))
      {
          int[,] arr = new int[iT, iT];
          for (int i = 0; i < iT; ++i)
          {
              string[] strInput = Console.ReadLine().Split();
              for (int j = 0; j < iT; ++j)
              {
                  arr[i, j] = int.Parse(strInput[j]);
              }
          }

          int[] answer = Solution(arr);
          for (int i = 0; i < answer.Length; i++)
          {
              Console.WriteLine(answer[i]);
          }
      }
  }
}
