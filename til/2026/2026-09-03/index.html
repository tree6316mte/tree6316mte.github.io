      Spring 입문 1주차 클리어

      오늘은 Spring 입문 1주차를 다 끝냈다

      Spring 입문 강의

      정적 페이지와 동적 페이지

      resources 폴더 안에 정적인 static 폴더와 동적인 templates 폴더

      원래는 static폴더만 작동하는데, thymeleaf 추가 시 Controller의 반환값을 가로채서 static 폴더에서 파일을 찾는다

      만약 thymeleaf가 있을 때 static폴더로 접근하고 싶다면, Controller의 반환값을 못가로채게 x.html파일로 바로 접근하거나 반환값을 redirect:x.html로 사용해서 우회하여야 한다


      <Template engine 더보기>

      Groovy: 스프링 부트 공식 지원 4대장 중 하나
      FreeMarker: 특정 설정 파일 텍스트를 자동 생성해야 할 때 현역
      Jade : 기존 HTML 형태를 완전히 파괴해버리기 때문에 호불호 심함
      Mustache: 로직 없이 데이터만 쏙 끼워 넣는 가벼운 토이 프로젝트용
      JSP: 원시 고대 표준 기술 (요즘 신규 프로젝트에서는 거의 퇴출)


      설명을 위한 예시 코드 HtmlController.java 

      @Controller
public class HtmlController {

    private static long visitCount = 0;

    @GetMapping("/static-hello")
    public String hello() {
        return "hello.html";
    }

    @GetMapping("/html/redirect")
    public String htmlStatic() {
        return "redirect:/hello.html";
    }

    @GetMapping("/html/templates")
    public String htmlTemplates() {
        return "hello";
    }

    @GetMapping("/html/dynamic")
    public String htmlDynamic(Model model) {
        visitCount++;
        model.addAttribute("visits", visitCount);
        return "hello-visit";
    }
}

      데이터를 Client에 반환하기

      Class를 데이터로 넘겨줘도 Jackson이라는 라이브러리 덕분에 자동으로 Json형식으로 넘김

      단, 반드시 Class에 @Getter어노테이션이나 getXXX메서드가 달려 있어야 함

      Jackson

      Jackson이 제공하는 Class <=> Json 변환되는 함수 2가지
      objectMapper.writeValueAsString((Class)instance): class => json (@Getter 필요) objectMapper.readValue((String)instance, (Class).class): json => class (기본 생성자 + (@Getteror@Setter) 필요)



      Path Variable과 Request Param

      함수의 매개변수에 사용되는 어노테이션

      /star/{name}/age/{age} 이렇게 URL 경로에서 데이터 받으려면 @PathVariable을 사용

      ?name=Robbie&age=95 이렇게 URL 경로 마지막에 ? 뒤에 데이터를 받으려면 @RequestParam을 사용

      @RequestParam(required = false) 하면 값 전달 못받았을 때 null로 초기화

      @Controller
@RequestMapping("/hello/request")
public class RequestController {
    @GetMapping("/form/html")
    public String helloForm() {
        return "hello-request-form";
    }

    // [Request sample]
    // GET http://localhost:8080/hello/request/star/Robbie/age/95
    @GetMapping("/star/{name}/age/{age}")
    @ResponseBody
    public String helloRequestPath(@PathVariable String name, @PathVariable int age)
    {
        return String.format("Hello, @PathVariable.<br> name = %s, age = %d", name, age);
    }

    // [Request sample]
    // GET http://localhost:8080/hello/request/form/param?name=Robbie&age=95
    @GetMapping("/form/param")
    @ResponseBody
    public String helloGetRequestParam(@RequestParam(required = false) String name, int age) {
        return String.format("Hello, @RequestParam.<br> name = %s, age = %d", name, age);
    }

    // [Request sample]
    // POST http://localhost:8080/hello/request/form/param
    // Header
    //  Content type: application/x-www-form-urlencoded
    // Body
    //  name=Robbie&age=95
    @PostMapping("/form/param")
    @ResponseBody
    public String helloPostRequestParam(@RequestParam String name, @RequestParam int age) {
        return String.format("Hello, @RequestParam.<br> name = %s, age = %d", name, age);
    }
}


      HTTP 데이터를 객체로 처리하는 방법

      @ModelAttribute: URL 쿼리 파라미터나 HTML 폼에서 데이터 하나씩 Java객체로 매핑
      @RequestBody: HTTP 요청 본문(JSON 데이터 등)을 한번에 통째로 Java 객체로 변환

      매개변수 생략 시 기본 값

      매개변수가 SimpleValueType(단순 값 타입) 맞다면 @RequestParam가 생략되어 있음

      매개변수가 SimpleValueType(단순 값 타입) 아니라면 @ModelAttribute가 생략되어 있음

      따라했더니 Spring을 통해 Memo가 잘 만들어 졌다



      Database

      Database는 데이터의 집합을 의미

      깨알 DB용어

      DBMS: DB를 관리하고 운영하는 소프트웨어를 의미
      RDBMS: 관계형 데이터 베이스를 의미

      DDL

      CREATE: 데이터베이스 생성
      ALTER: 데이터베이스와 테이블의 내용 수정
      DROP: 데이터베이스 삭제
      TRUNCATE: 최초 테이블이 만들어졌던 상태로 수정

      DCL

      GRANT: 사용자 또는 ROLE에 대해 권한을 부여
      REVOKE: 사용자 또는 ROLE에 부여한 권한을 회수

      DML

      INSERT: 테이블에 새로운 row를 추가
      SELECT: 테이블의 row를 선택
      UPDATE: 테이블의 row의 내용을 수정
      DELETE: 테이블의 row를 삭제


      JDBC 설정

      JDBC는 Java에서 Mysql같은 데이터 베이스를 손쉽게 연동해주는 도구이다

      Intelij에서 DB연결은 다음과 같다

      build.gradle의 dependencies에 종속성 설정 추가 

      // MySQL
implementation 'mysql:mysql-connector-java:8.0.28'
implementation 'org.springframework.boot:spring-boot-starter-data-jdbc'

      application.properties 설정 

      spring.datasource.url=jdbc:mysql://localhost:3306/memo
spring.datasource.username=root
spring.datasource.password=비밀번호직접입력
spring.datasource.driver-class-name=com.mysql.cj.jdbc.Driver

      Intelij에서 쿼리 작성을 위한 DB연결

      왼쪽의 DB 아이콘 눌러주고 데이터 소스를 MySQL로 만든다

      사용자,비밀번호,생성된 데이터베이스를 입력해주고 연결해준다
