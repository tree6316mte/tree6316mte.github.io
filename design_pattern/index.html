      디자인 패턴의 모든 예시는 Unity C#을 기준으로 작성되었습니다.

      디자인 패턴을 알아야 하는 이유

      디자인 패턴은 프로젝트를 진행하며 코드를 만들다 보면 코드 구조를 어떻게 해야 할지 고민하게 되고, 그때 자기도 모르게 이러한 디자인 패턴들 중 하나를 사용하고 있을 것입니다.

      하지만 그러한 고민을 한 사람은 당신만이 아니며, 그 코드 구조를 분류해서 만들어 놓은 것이 디자인 패턴이고, GOF는 그 중 23개의 대표적인 패턴을 정리하고 문서화했습니다.

      디자인 패턴을 알게 된다면 머리 아프게 어떤 구조로 짜야 할지 계속 생각할 필요 없이, 다른 사람이 고민해서 만들어 놓은 디자인 패턴을 참고하면 됩니다.

      그리고 개발자 간의 소통에서 질문하거나 물어볼 때 "○○ 패턴으로 만들었어" 라고 말한다면, 소통이 한층 더 원활해질 것이므로 익혀두시면 필히 도움이 됩니다.

      디자인 패턴 분류

      디자인 패턴은 크게 생성(Creational), 구조(Structural), 행위(Behavioral) 3가지로 나뉩니다.

      이는 객체를 “어떻게 만들고”, “어떻게 조합하며”, “어떻게 동작하게 할 것인가“에 따라서 분류되었습니다.

      • 생성 패턴 : 객체의 생성과정에 관여하는 패턴
      • 구조 패턴 : 클래스나 객체의 합성(+)에 관한 패턴
      • 행위 패턴 : 클래스나 객체들의 상호작용(<=>)과 책임을 분산하는 방법
